# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/),
e este projeto adere ao [Versionamento Semântico](https://semver.org/lang/pt-BR/).

## [1.0.0] - 2025-12-25

### Adicionado

- Visualização em matriz organizada por tipo de normativa e mês
- Visualização em lista com tabela ordenada por data
- Visualização em timeline cronológica
- Filtro por texto (busca no nome e descrição)
- Filtro por tipo de normativa (CMN, BCB, Instrução Normativa)
- Filtro por mês de publicação
- Modal de detalhes com link direto para o site do BCB
- Exportação dos dados filtrados em JSON
- Tooltip com resumo rápido ao passar o mouse
- Design responsivo para mobile
- Sidebar com toggle para dispositivos móveis
- Estatísticas em tempo real (total, por tipo)
- GitHub Actions para deploy no GitHub Pages
- GitHub Actions para lint de arquivos Markdown

### Tecnologias

- HTML5 semântico
- CSS3 com variáveis customizadas, Flexbox e Grid
- JavaScript ES6+ (Vanilla JS)
- Font Awesome para ícones
- Google Fonts (Roboto)
